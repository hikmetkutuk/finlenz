## Admin API

Set `ADMIN_API_KEY` before starting the backend. Override mutations require
`Authorization: Bearer <ADMIN_API_KEY>`.

Deleting an override clears its sector and industry immediately. Restart the
backend to run the TradingView sync and restore the source values.
